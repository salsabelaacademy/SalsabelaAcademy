# مراجعة وتحسين نسخة الأكاديمية المرفقة

## التعديلات
- تحسين قائمتي الموقع ولوحة التحكم، مع الحفاظ على التوسيع والإغلاق وروابط الصفحات.
- تبديل اللغة من قائمة الهاتف يغلق القائمة ويعرض شعار التحميل لمدة قصيرة (480 مللي ثانية)، دون تأخير التنقل أو إضافته إلى كل ضغطة.
- توحيد مظهر المقالات ومحرر المقالات والخدمات المرتبطة مع ألوان لوحة التحكم في الوضعين الليلي والنهاري.
- تنظيم الملف الشخصي إلى بيانات شخصية وتفضيلات وصورة وأمان الحساب، مع استمرار الحفظ الفعلي.
- إظهار الملف الشخصي المحفوظ للطالب لمدير الأكاديمية، مع نشاط الحصص والحضور والتقارير والتنبيهات ودائرة الإنجاز بفترات قابلة للتغيير. البيانات الغائبة تظهر بصراحة، ولا تُختلق إنجازات.
- إضافة مسار خلفي محمي خاص بالمدير لجلب تفاصيل طالب واحد؛ لا يعرض كلمات المرور أو الرموز أو روابط مضيف Zoom.
- تحسين نصوص «عن الأكاديمية»، وتغيير دعوة التواصل إلى «اكتشف نقطة بدايتك — احجز تقييمك المجاني» مع الترجمة الإنجليزية.
- خلفية محلية أعلى تفاصيل الدورة، وتحسين ترتيب صورة الدورة وبياناتها وأزرارها، دون حذف الدورات التسع أو محتواها.
- إكمال بيان الخلفيات لجميع الصور السبع وإضافة ملفات WebP محسّنة وطلب الصور مبكرًا من HTML وعند التنقل. أحجام الخلفيات بين 43 و219 كيلوبايت تقريبًا؛ سرعة أول زيارة تبقى مرتبطة بالاتصال والاستضافة.
- استمرار إخفاء مشاركة Drive التي طلبت إزالتها سابقًا من واجهة الخدمات المرتبطة. هذا لا يلغي صلاحيات Google السابقة من حساب Google نفسه.

## التحقق
- npm run verify: نجح (TypeScript وLint والبناء الإنتاجي).
- 72 فحصًا للتعديلات: نجحت؛ تشمل صلاحيات تفاصيل الطالب، بياناته الحقيقية، الدورات التسع، تطابق مفاتيح الترجمة، تحميل الخلفيات مبكرًا، حفظ مسودة مقال فعليًا، قائمة الهاتف وتبديل اللغة.
- 75 فحصًا للأمان والمصادقة والروابط والبيانات: نجحت.
- فحص العرض عند 320 و375 و390 و768 و1024 و1440 بكسل للصفحات المعدلة، والعربية والإنجليزية والوضعين الليلي والنهاري؛ لا تجاوز أفقي في الحالات المختبرة.
- لا أخطاء تشغيل JavaScript في جلسة المتصفح المختبرة.
- مراجعة بصرية للقطات المحرر والخدمات المرتبطة والملف الشخصي وتفاصيل الطالب وقائمة الهاتف وتفاصيل الدورة.
- الاختبارات تستخدم قاعدة معزولة وحسابات اختبار فقط، ولا تنشئ حسابات تجريبية في مشروعك. لم تُختبر خدمات Zoom أو Google أو إشعارات الهاتف على حسابات إنتاجية.
- حجم حزمة البداية: 496.15 كيلوبايت (160.76 مضغوطًا)، والمحرر المنفصل: 431.23 كيلوبايت (135.45 مضغوطًا). هذا قياس النسخة الحالية، وليس ادعاء مقارنة أداء مع نسخة أخرى.

## تركيب الملفات المعدلة
1. احفظ نسخة احتياطية من مشروعك وقاعدة البيانات قبل الاستبدال.
2. فك ملف التعديلات داخل جذر مشروع النسخة المرفقة، محافظًا على المسارات. لا تستبدل ملف الأسرار أو إعدادات قاعدة البيانات.
3. إن استخدمت النسخة الكاملة بدلًا منه، فهي شفرة المشروع دون node_modules أو dist أو الأسرار أو قاعدة البيانات.
4. نفّذ npm ci ثم npm run verify.
5. لا توجد هجرة قاعدة جديدة في هذا التعديل. إذا لم تكن طبّقت هجرة بيانات الحساب السابقة 0009، نفّذ npm run db:migrate:account قبل تجربة معلومات الملف الشخصي الجديدة.
6. أعد تشغيل المشروع ثم جرّب من الهاتف: فتح القائمة، تبديل اللغة، إغلاق القائمة وظهور التحميل القصير.
7. ادخل بحساب المدير الموجود لديك، وافتح الطلاب ثم التفاصيل، والمقالات ثم مقال جديد، والخدمات المرتبطة، والملف الشخصي في الوضعين الليلي والنهاري.
8. راجع /ar/about و/ar/contact وصفحة تفاصيل دورة، ثم نظائرها الإنجليزية. بيانات الطلاب والإنجازات تأتي من قاعدة مشروعك؛ لقطات التسليم تستخدم بيانات اختبار معزولة.

## حدود التسليم
التعديلات أُجريت على ملف المشروع الذي أرفقته؛ لم تُنشر إلى Replit أو الاستضافة، ولم تُعدّل قاعدة بياناتك الحية. لم تُضف متغيرات بيئة جديدة، ولم تُغيّر بيانات الدخول. لا تتضمن حزم التسليم ملفات الاختبار الخارجية أو الأسرار.
