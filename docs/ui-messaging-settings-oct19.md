# مراجعة الواجهة والمحادثات والإعدادات — الجولة الحالية

## المصدر وحدود الوصول

استُخرج آخر مشروع كامل محفوظ متاح في هذه الجلسة، وأُنشئت نقطة Git قبل التعديل `12e12ec`. لا يحتوي الأرشيف على سجل Git الأصلي، لذلك لا يُستبدل سجل مستودع المستخدم عند تركيب الحزمة. فُحصت الصور المرفقة؛ لم تُفترض مطابقتها للخادم الحي. قاعدة Replit وإعدادات الخدمات الخارجية غير متاحة لهذه الجولة.

## المشاكل المتحققة والتغييرات

- نموذج ActionForm داخل لوحة التفاصيل لم يحمل صنف التنسيق المستخدم في CSS؛ أضيف صنف صريح وشبكة حقول متجاوبة، مع تنسيق بطاقات حصص الطالب والتقارير. تستخدم النوافذ المنقولة عبر Portal ألوانها الخاصة الصحيحة في الوضعين.
- صفحتا التكاملات والمقالات احتفظتا بخلفية صفحة مستقلة داكنة داخل الداشبورد. وُحّدت أسطحهما وحدودهما مع سطح الداشبورد دون حذف مضمونهما.
- زر واتساب كان موجودًا وغير مركّب في الشجرة المعروضة. أعيد إلى الصفحات العامة وحدها بالرقم الموجود في المصدر.
- نافذة المحادثات: زر دائري أخضر بأيقونة Lucide، واجهة استقبال بعناصر حقيقية، رأس محادثة أبسط، فقاعات ونموذج إرسال متجاوبان، وقائمة أدوات فعلية للبحث في الرسائل المحمّلة وتنزيل المحادثة وتوسيع النافذة. لا صور فريق أو رسائل ترحيب مختلقة، ولا أزرار مرفقات/صوت بلا تنفيذ.
- إعداد البريد كان يبدأ بقيمة مفعلة رغم فشل قراءة الخادم. لا يُعرض المفتاح الآن قبل تحميل القيمة؛ عند الفشل توجد إعادة محاولة. يثبت نجاح الكتابة من القيمة المعادة من SQL RETURNING، وتبقى القيمة السابقة عند فشل الكتابة. أزيل إشعار الخطأ العام المكرر لهذا الطلب فقط.
- حفظ بيانات الأكاديمية كان UPDATE قد يعيد نجاحًا بلا تغيير إذا غاب السجل الوحيد. أصبح UPSERT حقيقيًا مع تحقق صارم من الحقول.
- تشغيل التطوير لم يكن يعيد تحميل ملفات الخادم، رغم تحديث الواجهة عبر Vite. أضيف Node watch، ويُعلن الخادم الحالي دعم SSE صراحةً؛ الواجهة لا تفتح مسار الأحداث على نسخة قديمة لا تعلن دعمه. التحديث الدوري يبقى بديلًا. لا تثبت هذه الملاحظة وحدها سبب كل خطأ 400 في الخادم الحي.
- إغلاق تدفقات SSE عند إيقاف الخادم، والتعامل مع أخطاء قاعدة البيانات المغلفة، وتسجيل فشل قراءة/كتابة التفضيلات بأسماء ورموز آمنة دون SQL أو مفاتيح.
- خلفية صفحة عن الأكاديمية أصبحت تستخدم الصورة المحلية ونفس التلاشي إلى سطح الصفحة؛ رابط حصتها التجريبية يذهب إلى apply مباشرة.

## ما لم يُنفذ على حسابات حية

لم يُرسل بريد حقيقي أو Push للهاتف، ولم تُنشأ اجتماعات Zoom أو أحداث Google، ولم يجرِ تسجيل OAuth على حساب المستخدم. حالات غياب إعداد هذه الخدمات اختُبرت دون نجاح وهمي. لم يُصلَح مخطط قاعدة Replit تخمينًا، ولم تُنفذ ترحيلات أو حذف بيانات عليها. يبقى سبب فشل الحفظ الحي بحاجة إلى سجل الخادم بعد تركيب الملفات المطابقة وإعادة التشغيل.

لم تُعد واجهات المعلم أو ولي الأمر، ولم تُضف حسابات تشغيل تجريبية، ولم تُحذف دورات أو صفحات أو اختبارات المستخدم. الإصلاحات محددة فوق النسخة الموجودة، وليست استبدالًا شاملًا للموقع.

## نتائج التشغيل الفعلية

- `npm ci --no-audit --no-fund`: نجح التثبيت النظيف. لم يُعد تشغيل npm audit في هذه الجولة؛ تقارير التدقيق الأقدم داخل المشروع تاريخية.
- `npm run verify`: نجحت TypeScript وESLint وبناء الإنتاج.
- مجموعة SQL/API/HTML/المتصفح الكاملة: **249 فحصًا نجحت**. طُبقت الترحيلات الـ13 داخل قاعدة PGlite فارغة، وأعيد SQL الإضافي المحدد في السكربت مع الحفاظ على بيانات الاختبار.
- 32 حالة داشبورد: المدير والطالب، العربية والإنجليزية، 320/390/768/1440، الوضعان الليلي والنهاري. شملت إرسال رسالة حقيقية إلى مسارات Express، حفظ التفضيلات وإعادة تحميلها، لوحة الإشعارات، القائمة الجانبية والملف الشخصي. أقسام الطلبات والطلاب والحضور ورسائل التواصل وسجل العمليات والبرامج وزيارات التفاصيل اختُبرت في الحالات الملائمة لكل دور بعرض 390 و1440.
- 54 زيارة للصفحات العامة: الرئيسية، الدورات، تفاصيل دورة، التقديم، الدخول، عن الأكاديمية، الأسعار، كيف تبدأ، التواصل؛ باللغتين وعرض 320/768/1440. جرى التحقق من عدم التمرير الأفقي، غياب أخطاء JavaScript أثناء الزيارات، وحضور واتساب في العام وغيابه داخل الداشبورد.
- متصفحان منفصلان وجلسات حقيقية: إرسال المدير يظهر عند الطالب دون إعادة تحميل. اختُبر منع وصول طالب لمحادثة طالب آخر، ومنع تكرار الرسالة، وحفظ إشعارها وطابور البريد، والتراجع عند خطأ إدراج SQL. اختُبر فشل الإرسال في الواجهة مع الاحتفاظ بالمسودة.
- تفضيلات البريد: قراءة وكتابة وإعادة قراءة فعلية؛ فشل الحفظ لا يبدل القيمة؛ فشل القراءة يخفي المفتاح ويعرض إعادة المحاولة، ثم يتعافى عند عودة الخدمة. اختُبر أيضًا حفظ إعدادات الأكاديمية، إنشاء سجل الإعدادات إذا كان مفقودًا، وحفظ الملف الشخصي ومنع تغيير الدور أو منطقة زمنية غير صحيحة.
- الالتحاق، قبول الطلب، الدعوة عند غياب البريد، إنشاء الحصة وإعادة جدولتها وإلغاؤها، التكرار الأسبوعي مع تغير التوقيت الصيفي، التقرير الوحيد وإكمال الحصة، صلاحية رابط مضيف Zoom، إدارة المقال وتنقية HTML: اختُبرت عبر المسارات والتخزين الحقيقيين في القاعدة المعزولة. لم يكن رد Gemini المحاكى إلا داخل الاختبار.
- اختُبرت قائمة أدوات المحادثة: البحث، تنزيل ملف السجل، والتوسيع. اختُبر مسار SSE وإغلاقه والتصريح بدعمه من الخادم.
- `watch-restart.mjs`: أثبت تشغيل Node watch إعادة تشغيل عملية TypeScript فعلًا بعد تغيير وحدة مستوردة.
- روجعت لقطات فعلية للمحادثة والاستقبال والإعدادات والتكاملات والمقالات وجدولة الحصة على الهاتف في الوضع الليلي. عُدّل لون عنوان المحادثة الحديثة بعد المراجعة؛ نسبة تباينه المحسوبة مع البطاقة **8.90:1**.

هذه اختبارات مسارات ووظائف وتخطيط محددة، وليست ضمانًا بخلو جميع الحالات الممكنة أو حسابات الإنتاج من الخطأ. تحذير حجم حزمة المتصفح ما زال قائمًا: نحو 638 كيلوبايت غير مضغوطة للحزمة الرئيسية، نحو 209 كيلوبايت gzip، وحزمة الخادم نحو 1.5 ميغابايت. لم تُجر مقارنة أداء قبل/بعد في هذه الجولة.

دليل التركيب والتشغيل موجود في `UPDATE-OCT19-AR.md`. حزمة QA المنفصلة تضم السكربتات وسجلات الجولة الحالية، ولا تُضاف اعتماديات الاختبار إلى تشغيل الأكاديمية.

بعد تعديل لون التباين الأخير أعيد `npm run verify` بنجاح، وشُغّلت جولة تحقق موجهة من **200 فحص ناجح** تشمل المسارات وحالتي المحادثة والإعدادات والمتصفحين والصفحات العامة، وتحقق المتصفح من اللون النهائي فعليًا. هذه الجولة تعيد جزءًا من اختبارات الجولة الكاملة وليست 200 وظيفة جديدة.
