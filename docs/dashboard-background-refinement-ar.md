# مراجعة الخلفيات واللوحة — 2 أكتوبر 2026

هذه التعديلات مبنية على آخر حزمة كاملة سُلّمت للمشروع. حُفظت نقطة بداية Git قبل التعديل، ولم تُنشأ حسابات أو بيانات تجريبية في قاعدة الإنتاج.

## التعديلات

- خلفيات الدورات والأسعار والمقالات وكيف تبدأ والتواصل تتلاشى إلى الشفافية، فوق لون الصفحة نفسه. أزيل حدّ الفصل أسفل هذه المقدمات. الصفحة الرئيسية لم تتغير.
- البحث داخل اللوحة يقرأ بيانات PostgreSQL الفعلية، بدل الاقتصار على أسماء الأقسام. يدعم أكثر من كلمة، ويتجاوز اختلاف الهمزات والتشكيل العربي والحروف اللاتينية المشكّلة. يظهر مقتطفًا حول الكلمة المطابقة، ثم يفتح القسم والسجل المطلوب ويضع التركيز عليه. يمكن فتحه بالزر أو Ctrl+K / ⌘K، واختيار أول نتيجة بـ Enter.
- المدير يبحث في الطلاب والطلبات والحصص والرسائل والإشعارات والحضور ورسائل التواصل وآخر 200 عملية مسجلة والمقالات. الطالب يبحث في حصصه وواجباته ورسائله وإشعاراته وحضوره والدورات الملتحق بها وعناوين موارد Drive المعيّنة له. أسماء أقسام الخدمات والإعدادات متاحة للتنقل؛ مفاتيح الربط وكلمات المرور والروابط المضيفة ليست محتوى بحث.
- البحث محمي في الخادم، بمحددات ملكية الطالب، ومعاملات SQL، و40 نتيجة كحد أقصى، و160 حرفًا للطلب، وأول 8 كلمات بحث. لا يُحفظ الرد في ذاكرة التخزين العامة. الحد 90 طلب بحث في الدقيقة لكل حساب داخل عملية الخادم.
- زر تغيير لغة اللوحة انتقل من الهيدر إلى الملف الشخصي للمدير والطالب؛ تبقى اللغة والمسار الحالي ومعلمات القسم عند التبديل. تفضيل لغة مراسلات الطالب المخزّن في ملفه ما زال متاحًا بشكل مستقل.
- زر البروفايل ظاهر على الهاتف، وله مساحة لمس لا تقل عن 44 بكسل. الإشعارات والوضع الداكن والبحث وقائمة الهاتف تعمل بجانبه.
- أضيفت دائرة إنجاز بألوان هادئة وبيانات حقيقية: المكتمل ÷ (المكتمل + المجدول). الملغى لا يدخل الحساب. لوحة المدير تجمع حصص الأكاديمية، ولوحة الطالب تحسب حصصه فقط. عند غياب الحصص تظهر شرطة ورسالة توضيح؛ لا تظهر نسبة مختلقة. هذه نسبة إنجاز الحصص، وليست درجة إتقان الطالب أو شهادة.

## الصور الجديدة: روابط التحميل والأسماء

تعذّر تنزيل الصور من مواقع التصوير داخل بيئة التنفيذ الحالية. لم أستبدلها بروابط خارجية في الموقع ولم أضع صورًا مولدة. الخلفية المحلية الحالية تبقى إلى أن تضيف الصور. هذه اختيارات مقترحة لكل مقدمة، ويمكن استخدام صور أخرى تملك حقوقها بالأسماء نفسها.

1. افتح رابط الصورة، وراجع شروط الاستخدام في موقع المصدر، ثم اضغط Free download.
2. سمّ الملف بالاسم في الجدول. تُقبل أيضًا الامتدادات `.jpeg` و`.png` و`.webp`؛ لا تغيّر امتداد الصورة فقط إذا لم يكن مناسبًا للملف.
3. ضع الملفات في `client/public/images/` داخل المشروع، وليس بجانب ملف ZIP.
4. شغّل `npm run dev` للمعاينة، أو `npm run build` ثم `npm start` للإنتاج. تجهّز الصور تلقائيًا قبل التشغيل المحلي وقبل البناء. ويمكن تشغيل `npm run images:prepare` وحده.
5. تُنتج نسخة WebP بعرض أقصى 1600 بكسل دون تكبير الأصل، وتُحدّث خريطة الخلفيات تلقائيًا. احتفظ بالملفات الأصلية ليُعاد تجهيزها في البناء القادم.
6. لا تغيّر اسم `home-mosque.webp`؛ يظل مستخدمًا في الرئيسية وكخيار احتياطي للصفحات التي لم تضف صورها.

لا أوصي بصور فوتوغرافية خلف نماذج الدخول والتقديم أو داخل لوحة التحكم؛ الأسطح الهادئة أوضح للقراءة والعمل. صفحة «عن الأكاديمية» تحتفظ بصورها الحالية، وليس مطلوبًا تكرار خلفية المسجد فيها.

## التثبيت والاختبار بنفسك

- استبدل الملفات المعدلة في **نفس نسخة المشروع السابقة**، أو استخدم النسخة الكاملة. احتفظ بمتغيرات البيئة وقاعدة بياناتك. لا تستبدل الأسرار بأي بيانات اختبار.
- استخدم Node 22 أو 24 ضمن إصدار المشروع المدعوم، ثم `npm ci`.
- شغّل `npm run verify`: فحص TypeScript وlint وبناء الإنتاج. للتطوير `npm run dev`، وللإنتاج بعد البناء `npm start`.
- ادخل بحساب المدير الحقيقي، وافتح البحث وابحث باسم طلب أو طالب ثم اختر النتيجة. يجب فتح بطاقته الفعلية. جرّب أيضًا كلمة في محتوى رسالة أو عنوان مقال.
- ادخل بحساب طالب، وابحث عن عنوان إحدى حصصه أو واجباته. لا ينبغي العثور على حصص طالب آخر أو ملاحظات الإدارة.
- أضف حصة مجدولة وأكمل أخرى من واجهة إدارة الحصص، ثم حدّث اللوحة. ستتغير دائرة الإنجاز من البيانات المحفوظة. إلغاء الحصة يخرجها من مقام النسبة.
- افتح الملف الشخصي من صورة الحساب على الهاتف وغيّر اللغة. يجب أن تبقى داخل الملف نفسه في المسار العربي `/ar` أو الإنجليزي.
- افتح التواصل والدورات والأسعار والمقالات وكيف تبدأ، وراجع الانتقال من الخلفية إلى المحتوى بالوضعين الفاتح والداكن.

## حدود واضحة

الصور المقترحة لم تُنزّل بعد؛ إضافتها متروكة للخطوات السابقة. البحث مطابقة نصية محسّنة وليس ذكاءً اصطناعيًا؛ يبحث في النص المخزّن ولا يفسر مرادفات كل اللغات. البحث الجزئي الحالي مناسب لحجم الأكاديمية المعتاد؛ قواعد البيانات الكبيرة تحتاج فهرس بحث مخصصًا. محدد معدل البحث في ذاكرة عملية واحدة؛ عند تشغيل نسخ متعددة للخادم يمكن نقله إلى مخزن مشترك. تشغيل الخدمات الخارجية يبقى معتمدًا على إعداداتك السابقة ومفاتيحها الصحيحة.

توجد في الحزمة الملفات المعدلة وحدها، ونسخة المصدر كاملة، ولقطات الشاشة، ونتائج التحقق. لا توجد قاعدة إنتاج أو أسرار أو حسابات تجريبية ضمن نسخة المصدر.
