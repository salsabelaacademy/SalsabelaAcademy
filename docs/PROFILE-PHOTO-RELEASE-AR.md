# تحديث الصور الشخصية ومراجعة ما قبل النقل

## تركيب الملفات

طبّق الحزمة فوق تحديث القائمة والإشعارات والملف الشخصي السابق (a4e0fbc). احفظ نسخة احتياطية، ثم انسخ الملفات إلى المسارات نفسها دون استبدال مجلد المشروع بالكامل.

هذه المرة يحتوي التحديث على اعتماد جديد لمعالجة الصور. انسخ `package.json` و`package-lock.json` مع بقية الملفات، ثم نفّذ:

```bash
npm ci
npm run check
npm run lint
npm run build
```

شغّل المعاينة بـ `npm run dev`. وعلى الاستضافة النهائية شغّل `npm start` مع `NODE_ENV=production`. لا تحتاج هذه الحزمة إلى ترحيل قاعدة بيانات جديد؛ تستخدم حقل الصورة الموجود في جدول الحسابات.

## الصورة الشخصية

- من الملف الشخصي اختر «تغيير الصورة»، ثم صورة JPG أو PNG أو WebP حتى 5 ميجابايت.
- تُقصّ الصورة مركزيًا إلى مربع. تُصغّر في المتصفح قبل رفعها، ثم يتحقق الخادم من نوعها الفعلي ويعيد ترميزها إلى WebP بحجم 256×256 دون بيانات EXIF.
- تُحفظ النسخة الصغيرة في PostgreSQL ضمن الحساب، وتظهر في الملف الشخصي وشريط الأدوات والقائمة الجانبية. زر الإزالة يحذف الصورة المحفوظة ويعيد الحرف الأول من الاسم.
- لا تعتمد الصور على القرص المؤقت في Replit أو الاستضافة؛ نقل قاعدة البيانات ونسخها الاحتياطي يشمل الصور.
- الرفع يتطلب جلسة مسجّلة وصلاحية صاحب الحساب، مع حدود للحجم وعدد الطلبات، ورفض SVG والروابط الخارجية والملفات المزيفة. لا يمكن إرسال رقم مستخدم آخر لتعديل صورته.
- لا توجد خدمة صور خارجية أو مفاتيح جديدة. يجب تثبيت اعتماد `sharp` على الاستضافة بواسطة `npm ci`، وعدم نسخ node_modules من جهاز مختلف.

## تحسينات الواجهة والمحتوى

تحسين شريط الأدوات الثابت وتفاعل الأزرار وحقول النماذج، مع الحفاظ على العربية والإنجليزية والوضع الداكن وتقليل الحركة. بقيت وظائف اللوحات مرتبطة بواجهات الخادم الموجودة.

كانت صفحة الأسعار تعرض ثلاثة مبالغ ثابتة وباقات ذات المزايا نفسها. أزيلت المبالغ وادعاء «الأكثر شيوعًا» وتحديد مدة تقييم غير موثقة، وأصبحت الأزرار تفتح طلب التقييم الحقيقي وتوضح أن الرسوم تُؤكد بعد التقييم. لا يوجد دفع إلكتروني مفعّل في المشروع.

## حالة التشغيل الحقيقية

| الوظيفة | الحالة وما يلزم |
| --- | --- |
| بيانات اللوحات، الحسابات، الرسائل، الحضور والطلبات | عمليات على قاعدة البيانات؛ لا تعتمد على بيانات عرض محلية |
| رفع الصورة وتعديل الملف الشخصي | حفظ فعلي في الحساب مع تحقق وصلاحيات من الخادم |
| المقالات وآراء الطلاب | تظهر المنشورات فقط؛ الآراء تحتاج موافقة النشر، ولا تُنشأ آراء وهمية |
| البريد والدعوات واستعادة كلمة المرور | تحتاج RESEND_API_KEY وRESEND_FROM صحيحين وتسليم بريد ناجح |
| Turnstile | يحتاج مفاتيح وأسماء النطاقات النهائية؛ الإنتاج يرفض التشغيل دون المتغيرات الإلزامية |
| Zoom وGoogle | التكاملات الموجودة تحتاج بيانات اعتماد وربطًا صحيحًا؛ تبقى غير مهيأة عند غيابها |
| الدفع | غير مفعّل؛ لا توجد عمليات تحصيل إلكترونية |
| النشر وDNS | لم يُنفّذا في هذه الجلسة |

لا تعني الاختبارات المعزولة أن مفاتيح حساباتك أو إرسال البريد والاجتماعات الحقيقية قد اختُبرت. يلزم اختبار نهائي بحساباتك بعد ضبط بيئة الاستضافة.

## الاختبارات

- TypeScript وESLint وبناء الإنتاج.
- 26 تحققًا لمسارات العمل: البيانات الحقيقية، الصلاحيات، الحضور، الرسائل، الطلبات والتواصل.
- 75 تحققًا للمصادقة والأمان: تسجيل الدخول والدعوات والتحقق واستعادة كلمة المرور ورفض الأدوار المحظورة وقيود الطلبات وإعدادات الإنتاج.
- 24 تحققًا للصورة والواجهة: رفع حقيقي، تصغير وتنظيف، الحفظ بعد إعادة التحميل، الحذف، رفض الملفات المزيفة وطلبات حساب آخر، ومقاسات الهاتف والحاسوب.
- 24 تحققًا للصفحات العامة: ثلاث دورات في الرئيسية وتسع في الدورات، المقالات والآراء المنشورة فقط، المقاسات المختلفة وتقليل الحركة.
- فحص `npm audit --omit=dev`: صفر ثغرات معروفة في اعتمادات التشغيل وقت المراجعة، بعد تحديث معالجة الصور إلى sharp 0.35.5. تم اختبار تحميل المكتبة أيضًا بطريقة CommonJS التي يستخدمها بناء الخادم النهائي.

استُخدمت قواعد اختبار معزولة، وحُجبت أو حوكيت الخدمات الخارجية داخل الاختبارات. لا تتضمن الحزمة حسابات اختبار أو ملفات اختبارات أو أسرارًا.

## متطلبات النقل

التصميم الحالي للتشغيل: استضافة تدعم Node/Express مع PostgreSQL. لا يكفي رفع ملفات الواجهة وحدها. اتبع دليل `docs/deployment-ar.md` الموجود بالمشروع لإعداد النسخ الاحتياطي والترحيل والتراجع.

- `FRONTEND_URL=https://salsabela.com` في بيئة الإنتاج.
- `DASHBOARD_HOST=dashboard.salsabela.com` اختياري بعد إضافة النطاق إلى الاستضافة. التطبيق الحالي يحوّل هذا النطاق إلى صفحات اللوحات على النطاق الرئيسي ليحافظ على جلسة موحّدة؛ ليس نشرًا مستقلًا للوحة على نطاق آخر.
- `notifications.salsabela.com` نطاق إرسال البريد المرتبط بـ Resend، ولا يحتاج موقعًا أو سجل A تخمينيًا.
- أدخل DATABASE_URL وSESSION_SECRET ومفاتيح Turnstile وResend، ومفاتيح التكاملات التي ستستخدمها. احتفظ بسر تشفير التكاملات عند نقل قاعدة البيانات.
- حدّث نطاقات Turnstile وروابط رد Google OAuth وفق النطاق النهائي، واضبط HTTPS وإعداد الوكيل وفق الاستضافة الفعلية.
- انسخ قاعدة البيانات الحالية بما فيها المقالات والطلاب والدورات والصور؛ لا تبدأ بقاعدة فارغة إن كنت تريد بياناتك الحالية.
- بعد النقل اختبر دخول المدير والطالب، طلب تقييم جديدًا، تسليم الدعوة، تغيير الصورة، وإرسال البريد. اختبر Zoom وGoogle فقط بعد ربط حساباتك.

لم تُغيّر سجلات Cloudflare أو النطاقات أو أسرارك في هذه الجلسة.
