# مراجعة الموقع والترجمة وتجربة اللوحات

## ما أُنجز

- مراجعة الرئيسية، الدورات وتفاصيل الدورات التسع، الأسعار، كيف تعمل الأكاديمية، نبذة عن الأكاديمية، التواصل، المقالات وتفاصيلها، طلب التقييم، الدخول، واستعادة الحساب وتفعيله.
- مراجعة أقسام المدير والطالب، إدارة المقالات ومحررها، والتكاملات داخل إطار اللوحة.
- الحفاظ على التصميم الأصلي وصور الدورات التسع. لم تُحذف دورات أو وظائف أو ملفات أساسية.
- نقل العبارات الثنائية المكتوبة داخل الصفحات إلى ملفات ترجمة. استكمال ترجمة أدوات محرر المقالات وإعدادات النشر ورسائل النماذج والأخطاء والتواصل والتسميات المساعدة لقارئات الشاشة.
- إصلاح معاينة المقال عندما تختلف لغة المقال عن لغة لوحة الإدارة؛ يفتح الرابط نسخة اللغة الصحيحة.
- عرض تواريخ المقالات المحفوظة بتاريخ محلي حسب لغة الواجهة، ومواعيد موارد الطالب حسب منطقته الزمنية.
- فصل خطأ تحميل المقالات عن حالة عدم وجود مقالات، وإتاحة إعادة المحاولة.

## تفاعل اللوحات

- زر بحث عن الأقسام مع اختصار Ctrl+K أو ⌘K، تصفية مباشرة، دعم العربية والإنجليزية، تنقل بلوحة المفاتيح وإغلاق Escape.
- بطاقات الإحصاءات تفتح القسم المرتبط ببياناتها الفعلية.
- تحديث فعلي للبيانات، دون انتظار وهمي أو إعادة تحميل الموقع بالكامل.
- تحديث روابط حصص الطالب وموارده عند تحديث اللوحة. يحتفظ العرض بآخر البيانات إذا تعذر تحديثها، مع رسالة واضحة.
- حفظ القسم في معامل tab بالرابط؛ إعادة التحميل وتغيير اللغة يحافظان على القسم. الأقسام غير المسموحة لدور المستخدم تعود للنظرة العامة.
- تحسين حالات التحويم والتركيز والتحديث مع احترام إعداد تقليل الحركة. القائمة الجانبية والإشعارات تعمل على الهاتف والكمبيوتر.

لم تُضف صور خارجية أو صور جديدة مولدة. الخلفية مشتركة وتستفيد من التخزين المؤقت؛ أبعادها الفعلية 1600×2000. الخلفيات زخرفية ولا تُقرأ كصور محتوى بواسطة قارئات الشاشة.

## نتائج التحقق

- npm run check: نجح.
- npm run lint: نجح.
- npm run build: نجح.
- 777 فحصًا للمتصفح والروابط والترجمة والتجاوب والتنقل: نجحت.
- 75 فحصًا للأمان والحسابات والتطبيقات والدعوات والمحتوى وSEO: نجحت؛ البريد الخارجي محاكًى في الاختبارات فقط.
- 873 مفتاح ترجمة لكل لغة، مع تطابق مجموعتي المفاتيح.
- 509 استخدامات ثابتة لمفاتيح الترجمة فُحصت؛ لا مراجع مفقودة.
- المقاسات: 320، 375، 390، 768، 1024، 1440 بكسل. العربية RTL والإنجليزية LTR، والوضعان الفاتح والداكن، والقائمة والإشعارات والتنقل السريع.
- لا أخطاء JavaScript في جلسة اختبار المتصفح. تفاصيل الدورات التسع تُفتح على الخادم وبعد تحميل React.
- حماية لوحة المدير من الطالب، والتحويل للدخول عند غياب الجلسة، وبقاء البيانات عند فشل التحديث، وتحديث موارد الحصص، جرى التحقق منها.

اختبارات المتصفح تعمل على قاعدة بيانات معزولة وبيانات اختبار. لقطات اللوحات لا تمثل حساباتك الحقيقية. لا يتصل الاختبار بخدمات إنتاجية ولا يضيف حسابات تجريبية للموقع.

## تركيب الملفات

1. احتفظ بنسخة من المشروع الحالي.
2. انقل ملفات changed-files إلى المسارات المطابقة في مشروعك، أو استخدم full-source.zip كنسخة كاملة. لا تضع الملف المضغوط داخل مجلد تشغيل الموقع.
3. احتفظ بإعدادات الاستضافة والأسرار وقاعدة البيانات الخاصة بك؛ لا توجد أسرار حقيقية في الحزمة.
4. نفّذ npm ci ثم npm run verify.
5. شغّل npm run dev للمعاينة، أو npm start بعد البناء مع إعدادات الإنتاج اللازمة.

لا يتطلب هذا التحديث ترحيل قاعدة بيانات أو إعادة ضبط الحسابات. اختبارات المتصفح محفوظة خارج ملفات الإنتاج، ونتائجها ولقطات الشاشة مرفقة.

## طريقة الاختبار بنفسك

1. افتح / ثم /ar، وبدّل اللغة من كل صفحة. تأكد من بقاء الصفحة نفسها.
2. افتح جميع الدورات التسع من /courses و/ar/courses، ثم تفاصيل كل دورة.
3. راجع خلفيات الصفحات المذكورة بالجدول، في الوضعين الفاتح والداكن وعلى الهاتف.
4. ادخل بحساب المدير الحقيقي من /login أو /ar/login ثم /dashboard/admin أو /ar/dashboard/admin.
5. افتح البحث السريع بالزر أو Ctrl+K، وابحث عن الطلاب أو المقالات أو التكاملات، ثم افتح القسم.
6. اضغط سهم بطاقة إحصاء، وبدّل اللغة وأعد تحميل الصفحة؛ يجب أن يبقى القسم المختار.
7. افتح الإشعارات، وجرّب قائمة الهاتف وطي القائمة على الكمبيوتر.
8. من إدارة المقالات، افتح مقالًا إنجليزيًا والواجهة عربية؛ زر المعاينة يجب أن يفتح رابط المقال الإنجليزي الصحيح.
9. ادخل كطالب مقبول سبق تفعيل حسابه من الدعوة. راجع الحصص والمنطقة الزمنية والموارد، ثم حدّث اللوحة.
10. جرّب رابطًا غير موجود، ورسائل الخطأ عند انقطاع الاتصال. لا تختبر بإرسال طلبات وهمية إلى البريد الحقيقي.

## حدود المراجعة

المراجعة تخص هذه النسخة من المشروع؛ لم يُنشر تعديل على استضافة أو نطاق. تشغيل Zoom وGoogle والبريد وWeb Push على حساباتك الحقيقية يحتاج إعداداتها واختبارًا بعد النشر. المحتوى الذي يكتبه المدير أو الطالب، مثل نص المقال وعنوان الحصة، لا يترجم تلقائيًا؛ يُعرض كما أُدخل أو حسب حقول اللغة الموجودة.
