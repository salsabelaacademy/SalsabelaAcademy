# تحديث تصميم لوحة المدير والطالب

هذا تحديث واجهة للنسخة ذات المرجع `8e1c520`، وليس مشروعًا كاملًا.
نقطة الرجوع قبل التعديل: `dashboard-before-redesign-20260929`.

## التركيب

1. احتفظ بنسخة من مشروعك الحالي.
2. فك الحزمة، وانسخ الملفات إلى المسارات نفسها داخل المشروع، مع استبدال الملفات المطابقة فقط. لا تستبدل مجلد client بالكامل ولا تحذف بقية ملفاته.
3. شغّل `npm run check` ثم `npm run lint` ثم `npm run build`.
4. أعد تشغيل المشروع. لا تحتاج هذه الحزمة إلى مفاتيح جديدة أو تعديل قاعدة البيانات أو تثبيت مكتبات جديدة.
5. سجّل الدخول بحسابك الحالي. لوحة المدير: `/ar/dashboard/admin`، ولوحة الطالب: `/ar/dashboard/student`. للإنجليزية احذف `/ar` من المسار. لا تتضمن الحزمة حسابات أو كلمات مرور افتراضية.

## ما تغيّر

- قائمة جانبية كحلية وإبراز ذهبي للقسم النشط، وتنظيم أدوات اللغة والوضع الداكن والإشعارات والملف الشخصي.
- ملخص مختلف لكل دور يعتمد على استجابة `/api/portal` الحالية.
- جدول حصص قادمة مرتب حسب الوقت ويعرض المنطقة الزمنية؛ الضغط عليه يفتح إدارة الدروس الحالية.
- إجراءات سريعة، وأحدث الرسائل، وملخص النشاط والحضور، وحالة الاتصالات للمدير، وموارد الطالب المصرّح بها.
- قائمة هاتف تستخدم dialog، تدعم Escape واستعادة التركيز إلى زر القائمة.
- تنسيق موحد للأقسام والنماذج الموجودة وحركة ظهور خفيفة تحترم تقليل الحركة.
- عرض صريح للحالات الفارغة والاتصالات غير المهيأة، دون إحصاءات مصطنعة.

احتُفظ بفروع العمليات الموجودة في Dashboard.tsx؛ نُقلت الواجهة المشتركة وملخص النظرة العامة إلى DashboardLayout.tsx. لم تُحذف صفحات الموقع أو الكورسات أو وظائف الإدارة، ولم تُعدّل واجهات الخادم أو الصلاحيات.

- فُحص الدوران بالعربية والإنجليزية، والوضع الداكن، والتنقل في جميع التبويبات، والقائمة على الهاتف، وEscape واستعادة التركيز، وعدم ظهور روابط إدارة للطالب، وعدم ظهور الملاحظة الخاصة المختبرة، وعدم وجود أخطاء JavaScript أثناء تلك الاختبارات.

## اختبارك بعد التركيب

1. افتح لوحة المدير، وافحص الطلاب والطلبات والدروس والإعدادات بحسابك.
2. افتح لوحة طالب في نافذة خاصة وتأكد أن بياناته وحدها ظاهرة.
3. بدّل العربية والإنجليزية والوضع الداكن.
4. جرّب الهاتف: فتح القائمة، اختيار قسم، وإغلاقها باستخدام Escape عند توفر لوحة مفاتيح.
5. افتح الدروس والموارد والإشعارات للتأكد أن البيانات الفعلية من قاعدة مشروعك تظهر كما تتوقع.
