# تحديث المحادثات والإشعارات وقائمة الحساب — 9 أكتوبر 2026

## التغييرات
- نافذة المحادثات تحمل هوية الأكاديمية الكحلية والذهبية. تظهر نافذة جانبية على الكمبيوتر وتملأ الشاشة عند عرض 600 بكسل أو أقل، كما في الصور المرجعية.
- زر دائري للمحادثات مع عدّاد الرسائل غير المقروءة. انتقالات خفيفة عند الفتح والإغلاق والتنقل بين المحادثات والمساعد، مع احترام إعداد تقليل الحركة.
- قائمة المحادثات تعرض معاينة حقيقية لآخر رسالة وترتب المحادثات حسب النشاط. لا توجد صفحة رسائل منفصلة.
- زر الجرس يفتح صندوقًا يحتوي جميع إشعارات المستخدم، وليس آخر خمسة فقط. على الهاتف يملأ الشاشة؛ على الكمبيوتر يظهر صندوق جانبي أعلى اللوحة.
- إزالة صفحة الإشعارات وعنصرها من القائمة الجانبية. الروابط القديمة التي تحتوي `?tab=notifications` تفتح الصندوق فوق صفحة النظرة العامة.
- أزرار قراءة الإشعار وقراءة الجميع تعمل عبر الخادم. إعدادات إشعارات الهاتف داخل الصندوق تستعمل خدمة Web Push الحالية؛ لا تنشئ إشعارات وهمية.
- قائمة الأفاتار تعرض هوية المستخدم وبريده، والملف الشخصي والإعدادات والإشعارات وموقع الأكاديمية وتسجيل الخروج. لا توجد روابط مالية أو إجازات أو صفحات غير منفذة.
- الإنجليزية والعربية واتجاه RTL وLTR والوضعان الليلي والنهاري مدعومة.

## إرسال الرسائل
أُصلحت مشكلة فعلية في المسودة: بعد فشل إرسال رسالة، تعديل نصها كان يحتفظ بمفتاح المحاولة القديمة وقد يؤدي إلى تعارض. تحتفظ إعادة إرسال النص نفسه بالمفتاح لمنع التكرار؛ تعديل النص يولّد مفتاحًا جديدًا. تبقى المسودة عند الخطأ ولا تظهر رسالة نجاح كاذبة. نجاح المحادثة يظهر بوصول الرسالة إلى سجلها؛ لا يظهر تنبيه إضافي يغطي زر الإغلاق على الهاتف. يُمنع تبديل المستلم أثناء الحفظ.

حفظ الرسائل محمي بجلسة الخادم وتحقق الدور والمستلم النشط وحدّ الاستخدام والمعاملة ومنع التكرار. لا يمكن للطالب مراسلة طالب آخر أو الوصول إلى محادثاته.

**الخطأ الحي الذي ظهر لديك لا يحدد سببًا واحدًا.** ليس لدينا سجل خادمك أو اتصال قاعدة بياناته. لا يصح الادعاء أن خلل القاعدة الحية أُصلح بمجرد نجاح قاعدة الاختبار.

أُضيفت أخطاء واضحة مع رقم متابعة آمن للمدير، وسجل خادم مختصر يحدد مرحلة الفشل ورمز قاعدة البيانات دون نص الرسالة أو SQL أو مفاتيح. مراحل الحفظ تشمل حد الاستخدام والاتصال وحفظ الرسالة.

## ماذا تفعل إذا استمر خطأ الإرسال؟
1. ارفع تحديثات الواجهة والخادم معًا وأعد تشغيل المشروع، وليس الواجهة وحدها.
2. ادخل بحساب المدير وافتح نافذة المحادثات ثم أرسل رسالة لطالب نشط.
3. إذا فشلت، افتح «تشخيص الاتصال» ثم «فحص حفظ الرسائل بأمان».
4. الفحص محمي للمدير. يحاول حفظ مسودة وإنشاء إشعارها داخل معاملة ثم يلغي العملية بالكامل. لا تصل رسالة أو بريد أو إشعار إلى الطالب. قد تزيد أرقام التسلسل في PostgreSQL؛ هذا سلوك طبيعي حتى مع التراجع.
5. ظهور قبول المسودة يعني نجاح الحفظ في قاعدة البيانات. لا يعني اختبار Gemini أو Resend أو تسليم البريد.
6. إذا ظهر نقص في مخطط القاعدة، خذ نسخة احتياطية وراجع تحديثات المشروع السابقة بالترتيب. أوامرها تشمل `npm run db:migrate:dashboard` ثم `npm run db:migrate:email` وفق حالة قاعدة البيانات. في الإنتاج تتطلب هذه الأوامر `CONFIRM_DASHBOARD_MIGRATION=yes`. لا تستخدم `db:push` عشوائيًا على القاعدة الحية.
7. إذا استمر الفشل، ابحث عن `conversation_failure` ورقم المتابعة في سجل الخادم. أرسل نتيجة التشخيص ورمز الخطأ فقط؛ لا ترسل المفاتيح أو DATABASE_URL أو SQL أو بيانات الطلاب.
8. رموز مثل `42P01` أو `42703` تدل على جدول أو عمود ناقص؛ `42501` يدل على صلاحيات القاعدة؛ `23502` على قيد حقل مطلوب؛ `23503` على علاقة بيانات؛ `23505` على قيد تكرار؛ `57014` على إلغاء استعلام أو مهلة. تحتاج مراجعة الحالة الفعلية ولا تُصلح كلها بتغيير تصميم الواجهة.

الفحص محدود بثلاث محاولات خلال خمس دقائق. لا ينفذ ترحيلات تلقائيًا ولا يغيّر صلاحيات القاعدة أو يمنع حمايتها.

## التركيب
- خذ نسخة احتياطية من ملفاتك وقاعدتك.
- حزمة التعديلات تحتوي ملف `INSTALL-AR.md` وقائمة الملفات المطلوب حذفها أو استبدالها؛ أزل الملف القديم `NotificationCenter.tsx` بعد إضافة `NotificationFeed.tsx`.
- لا تغيّر Secrets أو قاعدة البيانات عند تبديل ملفات الواجهة. هذه النسخة لا تضيف ترحيلًا جديدًا.
- استخدم Node متوافقًا مع المشروع ثم `npm ci` و`npm run check` و`npm run lint` و`npm run build`، وبعدها أعد تشغيل الخادم.

## الاختبارات والحدود
النتائج التفصيلية محفوظة مع ملفات التسليم. اختبارات الخادم تستخدم PostgreSQL معزولًا عبر PGlite وتنفذ ترحيلات SQL الحقيقية. المتصفح يستخدم بيانات اختبار معلنة ومحاكاة طلبات الخدمات. لا تتصل الاختبارات بحسابات الإنتاج ولا تُنشئ حسابات تجريبية في الموقع الحقيقي.

لقطات الشاشة تستخدم بيانات اختبار لتوضيح التصميم فقط. لم يُنشر المشروع ولم تُختبر مفاتيحك الحقيقية. تحذير حجم الحزمة الأولية أكبر من 500 كيلوبايت ما زال ظاهرًا في البناء.
