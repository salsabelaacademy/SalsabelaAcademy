# تحديث الطلاب والتقارير والجدولة

هذا تحديث إضافي للنسخة السابقة، وليس إعادة إنشاء للأكاديمية. لم يُحذف أي حساب أو دورة أو صفحة أو بيانات فعلية. الأدوار المتاحة: المدير والطالب فقط. المدير هو المدرّس الوحيد.

## قبل التشغيل

1. خذ نسخة احتياطية من قاعدة البيانات وفق دليل النشر الموجود بالمشروع.
2. انسخ الملفات المعدّلة إلى مساراتها الأصلية، أو استخدم نسخة المصدر الكاملة.
3. شغّل `npm ci`.
4. لقاعدة بيانات موجودة ومكتملة حتى تحديث إشعارات الهاتف، شغّل `npm run db:migrate:followup`. في الإنتاج، بعد النسخ الاحتياطي ومراجعة SQL، استخدم `NODE_ENV=production CONFIRM_FOLLOWUP_MIGRATION=yes npm run db:migrate:followup`.
5. إذا لم تُنفّذ ترقية إشعارات الهاتف سابقًا، نفّذها أولًا حسب `docs/web-push-and-experience.md`. لا تستخدم ترحيل قاعدة جديدة على قاعدة موجودة.
6. لقاعدة فارغة فقط: `npm run db:migrate:fresh`، ويتضمن الآن الترحيل 0008. لا تحتاج إلى مسار الترقية اليدوية أيضًا.
7. شغّل `npm run verify` ثم أعد تشغيل الخادم. لا تُضاف جداول تلقائيًا عند بدء الموقع.

الترحيل الجديد ينشئ `lesson_followups` والفهارس، ويحسّن إشعار الحصة ليشمل تعديل نهاية الموعد ويمنع التنبيهات المتكررة عند حفظ نفس القيم. لا يحذف البيانات القديمة. الترقية اليدوية تعمل داخل معاملة، وتسجّل بصمة الترحيل؛ إعادة تشغيلها آمنة ما لم يتغيّر SQL بعد تطبيقه.

## صفحة الطلاب

- افتح لوحة المدير ثم الطلاب. ابحث بالاسم أو البريد، أو صفِّ حسب حالة الحساب.
- بطاقة الطالب تعرض بياناته الفعلية، والدورات الملتحق بها، وأقرب حصة. الأرقام ليست تجريبية.
- افتح البطاقة لعرض الملف والمنطقة الزمنية والحصص وسجل التقارير.
- تظل إجراءات إلحاق الطالب بالدورة وإيقاف الحساب وإعادة تفعيله موجودة.
- إعادة الجدولة متاحة للحصة المجدولة. المواعيد التي تُدخلها تستخدم المنطقة الزمنية لجهازك؛ التخزين UTC والعرض حسب منطقة مستخدم اللوحة.
- الحصة المكتملة لا تُعاد جدولتها. الحصة الملغاة لا تقبل تقارير أو تنبيهات جديدة. المواعيد المتداخلة مع حصة مجدولة أو تقييم مؤكد تُرفض لأن المدير هو المدرس الوحيد.

## التقرير

بعد بدء الحصة، اضغط «تقرير الحصة». اكتب ما تمت دراسته من جهازك، وحدد تقييم السلوك والمشاركة من 1 إلى 5، وأضف تعليقًا إن احتجت. يمكن تحديد «تعديل خطة التعلم» لإرسال طلب تعديل للنقاش مع الطالب؛ هذا ليس تعديلًا تلقائيًا لمنهج أو إنشاء مكتبة مناهج.

التقرير يُحفظ في قاعدة البيانات، ويظهر في إشعارات الطالب وفي تفاصيل حصته. يظهر في البحث داخل اللوحة أيضًا. لا يغيّر حالة الحصة إلى مكتملة تلقائيًا؛ يمكنك إكمالها من تفاصيل الموعد في الجدول.

## التنبيهات

الخيارات السبعة: تذكير، غياب أول، غياب ثانٍ، غياب ثالث أو أكثر، اعتذار، مغادرة مبكرة، وتأخر المدير. يمكن إضافة توضيح. تصنيف مرات الغياب يختاره المدير حسب سجل الطالب؛ لا تُنشأ أرقام غياب وهمية.

الغياب يسجّل «غائب»، والاعتذار «بعذر»، والمغادرة المبكرة «حاضر». يُحدَّث سجل الحصة نفسه دون تكرار سجلات الحضور. الغياب لا يمكن تسجيله قبل بدء الحصة. التذكير مخصص لحصة مجدولة لم تنتهِ. هذه التنبيهات لا تلغي الحصة تلقائيًا؛ الإلغاء إجراء مستقل.

كل إرسال له مفتاح طلب فريد، ومنع تكرار، وتحقق من صلاحية المدير، وسجل تدقيق. يُرفض تغيير محتوى طلب أُرسل بالفعل بنفس المفتاح. إغلاق النافذة وفتح إرسال جديد ينشئ طلبًا جديدًا. يوجد حد 60 متابعة في الساعة لكل مدير.

## الجدول

عرض شهر وأسبوع ويوم وقائمة، مع التنقل بين الفترات والعودة لليوم، والتصفية بحسب الطالب ونوع الموعد. الهاتف يبدأ بعرض القائمة. عرض الأسبوع يتيح تمريرًا داخل الجدول فقط، ولا يوسّع الصفحة. يبدأ التمرير قرب أول موعد مسجّل في الفترة، أو الساعة التاسعة عند خلوّها.

اضغط الموعد لعرض تفاصيله. تظهر أدوات التقارير والتنبيهات والواجبات والتعليقات والحضور وإكمال/إلغاء الحصص حسب صلاحياتك. زر «جدولة حصة» يفتح نموذج الإنشاء الحقيقي. التقييمات لها تفاصيل وأدوات إعادة الجدولة والإكمال والإلغاء للمدير. إعدادات Zoom وGoogle والمزامنة الحالية محفوظة؛ لا يعني حفظ الموعد نجاح مزامنة خارجية قبل تنفيذ المهمة بنجاح.

## الهاتف والخصوصية

لا توجد مفاتيح جديدة لهذا التحديث. إشعارات الهاتف تعتمد على إعدادات `WEB_PUSH_PUBLIC_KEY` و`WEB_PUSH_PRIVATE_KEY` و`WEB_PUSH_SUBJECT` الموجودة سابقًا، وHTTPS، وتشغيل الخادم/العامل باستمرار، واشتراك الطالب على جهازه.

الإرسال داخل الأكاديمية يُحفظ فورًا. إشعار الهاتف يُضاف إلى قائمة التسليم فقط لأجهزة الطالب المشتركة، مع إعادة المحاولة الآمنة. نص الهاتف مختصر ولا يحتوي التقرير أو الاسم أو الملاحظات الخاصة؛ الضغط يفتح صفحة الإشعارات المحمية. الجلسة المنتهية تتطلب تسجيل الدخول. التسليم يعتمد على الجهاز والمتصفح والشبكة؛ لم يُختبر هاتف إنتاج فعلي ضمن الاختبارات المعزولة.

## الصفحات العامة

- زر «ابدأ الآن» في الأسعار ينتقل إلى نموذج طلب الاشتراك مباشرة عبر `#contact-form`، بالعربية والإنجليزية، مع استمرار اختيار الخطة.
- خلفية «كيف تبدأ» تستخدم الصورة المحلية `page-journey-optimized.webp`، مع تموضع وتلاشي محسّنين نحو بقية الصفحة.
- الصور الخمس المرفوعة سابقًا مضمّنة محليًا ومحوّلة إلى WebP. الأصل المضغوط يستخدمه أمر `npm run images:prepare` لتجهيز نسخة العرض. لا يحتاج الموقع روابط صور خارجية.

## اختبارك قبل النشر

1. افتح الأسعار على الهاتف، واضغط «ابدأ الآن»: يجب أن يظهر نموذج الاشتراك دون البدء بأعلى صفحة التواصل.
2. افتح «كيف تبدأ» في الوضعين الفاتح والداكن وعلى الهاتف والكمبيوتر، وتأكد من تحميل الخلفية المحلية.
3. ادخل بحساب المدير، ثم الطلاب؛ افتح طالبًا له حصة فعلية.
4. أرسل تقريرًا لحصة بدأت، وسجّل تنبيهًا، وراجع سجل التدقيق والحضور.
5. ادخل بحساب هذا الطالب في متصفح آخر، وحدّث اللوحة: يجب أن تصل إشعاراته وتظهر تقاريره فقط، دون أدوات المدير أو ملاحظاته الخاصة.
6. فعّل إشعارات الهاتف من الملف الشخصي على نطاق HTTPS النهائي. أرسل تحديثًا جديدًا وتحقق من وصوله والجهاز مغلق اللوحة، ثم افتح التنبيه.
7. أعد جدولة حصة إلى موعد لا يتداخل مع موعد آخر. راجع وقت الطالب ومزامنة Zoom/Calendar من صفحة الخدمات.
8. راجع شهر/أسبوع/يوم/قائمة، والعربية والإنجليزية، و320/375/390/768/1024/1440 بكسل، ولوحة المفاتيح.

لقطات الشاشة المصاحبة مأخوذة من قاعدة اختبار معزولة، وليست حسابات أو بيانات تُضاف للمشروع. ملفات الاختبار وبياناته ليست ضمن مصدر الإنتاج.
