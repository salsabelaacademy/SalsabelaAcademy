# استعادة الأسعار وتوحيد لوحة التحكم

## التغييرات

- استعادة `client/src/pages/Pricing.tsx` حرفيًا من ملف الأسعار المرفق من المالك: الباقات الأصلية 9 و11 و13 دولارًا والتصميم والمزايا والأسئلة كما كانت. هذا الطلب يلغي قرار إخفاء الأسعار المذكور في التقرير السابق. لا يضيف نظام دفع إلكتروني.
- شاشة تحميل بالشعار في المنتصف و«جارٍ التحميل…» بالعربية وLoading… بالإنجليزية، عند تحميل الصفحة وتغيير اللغة.
- انتقالات الداشبورد داخل مساحة المحتوى مع بقاء القائمة والشريط العلوي. انتقال قصير 180 مللي ثانية للوحة و220 للصفحات العامة؛ الانتظار الفعلي للشبكة مستقل، ولا توجد مهلة إجبارية طويلة. تُحترم إعدادات تقليل الحركة.
- تحميل محرّر المقالات وقائمة المقالات والتكاملات والملف الشخصي وإدارة الآراء عند الحاجة. فصل موارد الطالب عن وحدة إدارة التكاملات.
- المقالات ومحررها والتكاملات داخل إطار لوحة المدير، بنفس القائمة والإشعارات واللغة والمظهر. روابطها القديمة تظل تعمل.
- إصلاح مؤقّت العودة بعد حفظ المقال الذي كان يمكن أن يسحب المستخدم من قسم آخر إلى قائمة المقالات.
- إغلاق قائمة الهاتف عند اختيار المقالات أو التكاملات، وتمييز القسم النشط، وتعريب قائمة المقالات وتحسين تسميات أزرارها.
- تصحيح مرجع دليل إعداد التكاملات إلى ملف موجود في المشروع.

## نتائج التحقق

- `npm run check` و`npm run lint` و`npm run build`: نجحت.
- 32 تحققًا لدمج اللوحة: تطابق الأسعار، تحميل الوحدات عند الحاجة، حفظ مسودة في قاعدة اختبار فعلية، التنقل إلى الملف الشخصي، منع الطالب من إدارة التكاملات، وعدم ظهور أخطاء JavaScript.
- 6 سيناريوهات للتحميل والتنقل: الشعار عند تغيير اللغة، انتقال محتوى اللوحة فقط، تحميل الملف الشخصي، وتقليل الحركة وإغلاق قائمة الهاتف بعد اختيار المقالات أو التكاملات.
- 56 تحققًا للقائمة والإشعارات والملف الشخصي والصلاحيات للمدير والطالب.
- 26 تحققًا لسير العمل و75 تحققًا للمصادقة والأمان.
- مراجعة الصفحات العامة بالعربية والإنجليزية عند 320 و375 و390 و768 و1024 و1440 بكسل، والتحقق من عرض 3 دورات في الرئيسية و9 في صفحة الدورات، والمقالات والآراء المنشورة وتقليل الحركة.
- مراجعة صفحات المقالات والتكاملات ومحرر المقالات عند 320 و375 و768 و1440 بكسل دون امتداد أفقي للصفحة. الجداول العريضة قابلة للتمرير داخل حاويتها.
- محرر المقالات حزمة مستقلة تقارب 430 كيلوبايت قبل الضغط و135 كيلوبايت gzip، ولا تُحمّل مع فتح الداشبورد. التكاملات حزمة مستقلة تقارب 14 كيلوبايت و4 gzip.

الاختبارات استخدمت قاعدة معزولة دون الاتصال بحسابات Zoom أو Google أو إرسال بريد حقيقي. الصور تعرض بيانات اختبار، ولا توجد هذه الحسابات أو المقالة الاختبارية في الحزمة.

## تركيب حزمة التعديلات

1. خذ نسخة احتياطية من المشروع الحالي وقاعدة البيانات.
2. الحزمة تخص النسخة السابقة عند checkpoint `76a5225`. فكها داخل جذر المشروع ووافق على استبدال الملفات المتطابقة. لا تضعها داخل مجلد client وحده.
3. لا يلزم ترحيل جديد لقاعدة البيانات لهذا التحديث. احتفظ بملف البيئة والأسرار وبياناتك الحالية.
4. شغّل `npm ci` ثم `npm run verify`.
5. للتطوير شغّل `npm run dev`. للإنتاج استخدم `npm run build` ثم `npm start` بعد إعداد بيئة الإنتاج.

## استخدام النسخة الكاملة

الحزمة الكاملة تحتوي المصدر والأصول وملفات الترحيل وأدلة التشغيل، دون node_modules أو dist أو أسرار أو قاعدة بيانات أو حسابات اختبار. فكها في مجلد جديد، وأعد ضبط بيئة مشروعك وفق `.env.example` وأدلة `docs/deployment-ar.md` و`docs/integrations-ar.md`. لا تستبدل قاعدة بياناتك بقاعدة فارغة. لا يلزم تركيب حزمة التعديلات فوق النسخة الكاملة لأنها تتضمنها.

## اختبار سريع بعد التركيب

1. افتح `/pricing` و`/ar/pricing` وتحقق من الباقات الأصلية.
2. بدّل اللغة من الصفحة العامة ولاحظ شاشة الشعار ثم اكتمال الصفحة دون بقاء التحميل.
3. ادخل بحساب المدير وافتح المقالات، أنشئ مسودة، احفظها، ثم افتح التكاملات والملف الشخصي من القائمة.
4. كرر على الهاتف؛ افتح القائمة ثم اختر قسمًا وتأكد من إغلاقها. جرّب المظهر الداكن.
5. بدّل لغة اللوحة وتأكد من بقاء إطارها وظهور التحميل داخل المحتوى.
6. ادخل بحساب طالب وتأكد من عدم إتاحة إدارة المقالات أو التكاملات.

## حدود المراجعة

هذه النتائج تخص المصدر المحلي المختبر. لم تُعدّل الاستضافة أو DNS أو الأسرار، ولم تُثبت عمليات الربط الخارجية بحسابات الإنتاج. بعض أدوات التحرير المتقدمة في محرر المقالات القديم ما زالت بالإنجليزية؛ القائمة الأساسية والتكاملات مترجمة. لا تعني الاختبارات ضمان خلو كل بيئة نشر من الأخطاء، ويلزم فحص سريع بعد النقل باستخدام إعداداتك الحقيقية.
