# تقرير إصلاح النسخة المرفقة

## نطاق العمل وسبب الخلل

فُحص الأرشيف المرفق ومصدره وسجل Git. كانت مكونات وترجمات وخدمات خلفية مستوردة في الملفات الحالية غير موجودة في شجرة العمل. عُثر على تنفيذها في سجل المشروع، واستُعيدت من الشجرة التاريخية `70b517f` بدل إنشاء واجهات وهمية أو تعطيل فحص TypeScript. حُفظت تغييرات المستخدم في الاعتماديات بنقطة Git محلية `96aa278` قبل الإصلاح. احتُفظ بإصلاحات النسخة الحالية في المصادقة والمحادثات وتسجيل المسارات.

## التعديلات

- استعادة مكونات الطلاب والجدولة والتقارير والإشعارات والبحث والتفضيلات والملف الشخصي، وملفات CSS والترجمات اللازمة.
- استعادة خدمات التشخيص والرسائل المساندة وGemini وطابور البريد وقوالبه، وربط عامل البريد بدورة تشغيل وإيقاف الخادم.
- استعادة تسجيل مسارات الخدمات والحقول والترحيلات المتوافقة معها؛ لا تُنفذ الترحيلات تلقائيًا عند بدء التطبيق.
- استعادة حماية التقرير الوحيد لكل حصة؛ حفظ التقرير وإكمال الحصة داخل التدفق الخاضع للاختبار، مع التراجع عند الفشل.
- استعادة خلفيات الصفحات المحلية المشار إليها في المصدر، وتوافق خيارات مكونات اللغة واللوحة الجانبية والخلفيات.
- استخدام أيقونة MessageCircleMore من مكتبة Lucide الموجودة بدل الاستيراد المفقود.
- نقل tailwindcss-animate إلى devDependencies، وتثبيت حد DOMPurify الأدنى على النسخة الموجودة في القفل بعد إصلاح المستخدم، والإبقاء على override الخاص بـ proxy-addr 2.0.8.
- تصحيح ستة عناوين tarball خاصة ببروكسي Replit في القفل إلى عناوين سجل npm الرسمية للحزم نفسها، مع الحفاظ على integrity. لا تغيير لإعدادات جدار حماية Replit.
- إضافة أوامر تشخيص وترحيل صريحة ودليل تثبيت عربي؛ `.env.example` يتضمن أسماء المتغيرات فقط.

## نتائج تشغيل فعلية

| الفحص | النتيجة |
|---|---|
| npm ci — تثبيت نظيف | نجح |
| npm run verify — TypeScript وLint وبناء الإنتاج | نجح |
| npm audit --omit=dev | صفر ثغرات معلنة في شجرة الإنتاج وقت الفحص |
| npm audit — الشجرة الكاملة | 8 تنبيهات تطوير: 3 متوسطة و5 مرتفعة، ما زالت قائمة |
| اختبار الخادم المبني | health/live يعيد 200؛ التشخيص والمحادثات يعيدان 401 دون دخول؛ API مجهول يعيد 404 JSON |
| مجموعة SQL/API/المتصفح المعزولة | 189 فحصًا نجحت |

مجموعة الاختبار تتكون من 103 فحوص SQL/API/HTML ومنطق، و32 حالة داشبورد بالمتصفح، و54 زيارة للصفحات العامة. اختبارات الواجهة شملت العربية والإنجليزية، المدير والطالب، عرض 320 و390 و768 و1440 للداشبورد، والوضعين الليلي والنهاري. الصفحات العامة اختُبرت بعرض 320 و768 و1440 لكل لغة.

شملت الصفحات العامة الرئيسية، الدورات، تفاصيل دورة، التقديم، الدخول، عن الأكاديمية، الأسعار، كيف تبدأ، والتواصل. جرى التحقق من عدم التمرير الأفقي وأخطاء JavaScript، واتجاه اللغة، والقائمة الجانبية والملف الشخصي والمحادثات والإشعارات. هذا تحقق آلي للوظائف والتخطيط وليس تدقيق وصول شاملًا لكل عنصر أو مراجعة بصرية بشرية لجميع الصفحات.

## تدفق الرسائل والصلاحيات

شُغّلت مسارات Express الفعلية مع جلسات دخول حقيقية وقاعدة PostgreSQL معزولة عبر PGlite. نجح إرسال المدير إلى الطالب وقراءة الطالب للرسالة والرد، وحفظ الرسالة وإشعارها وطابور البريد. أُرسلت أيضًا رسائل من واجهة المتصفح إلى الخادم في حالات الداشبورد الـ32. اختُبر منع الوصول بين الطلاب ومنع الطالب من التشخيص ورابط مضيف Zoom، ومنع التكرار عند إعادة إرسال request key، وإظهار الفشل عند حقن خطأ تخزين دون نجاح وهمي. اختُبر فحص التشخيص الذي يتراجع عن كتاباته دون ترك بيانات تشخيصية.

اختُبرت نماذج التواصل والتقديم والتحقق من الدولة والهاتف وتكرار الطلب، والوصول للدورات التسع وتفاصيلها عبر API، والتقارير والتراجع عن إكمال الحصة إذا فشل حفظ التقرير، والتكرار الأسبوعي عند انتقال التوقيت الصيفي، وحالات نقص إعدادات البريد وGemini وZoom. استُخدم رد Gemini محاكى داخل الاختبار فقط.

## حدود النتائج والعمل الباقي

لم يُختبر الاتصال بقاعدة الإنتاج أو وصول البريد إلى الصندوق أو تنفيذ Gemini/Zoom/Google الحقيقي أو وصول Push للهاتف؛ يتطلب ذلك إعدادات وحسابات فعلية. جميع بيانات الاختبار معزولة، ولا حسابات تجريبية تُنشأ عند تشغيل الأكاديمية.

تدقيق التطوير لا يزال يحتاج معالجة متوافقة لسلسلة Tailwind 3 وbraces وpostcss-selector-parser. لم يُفرض override بإصدار رئيسي مختلف ولم تُنفذ ترقية Tailwind واسعة قد تغير التصميم. خروجها من تدقيق الإنتاج ليس إصلاحًا للثغرات نفسها.

البناء يعرض تحذير حجم: الحزمة الرئيسية نحو 515.75 كيلوبايت (168.52 مضغوطة gzip)، وحزمة الخادم نحو 1.5 ميغابايت. لم تُجرَ مقارنة أداء قبل/بعد لأن المصدر الأصلي المرفق لا يجتاز البناء بسبب الملفات الناقصة. تقليل الحزم عمل صيانة لاحق، وليس شرطًا تم الادعاء بإتمامه.

اختُبرت الترحيلات الـ13 على قاعدة فارغة وإعادة تطبيق SQL المستعاد 0008–0012 مع الحفاظ على عدادات بيانات الاختبار. لا تثبت هذه النتيجة أن قاعدة الإنتاج الحالية مطابقة؛ استخدم دليل INSTALL-REPAIR-AR.md قبل أي تعديل عليها.

حزمة QA المنفصلة تحتوي على سكربتات الاختبار وسجلات النتائج لإعادة التشغيل، دون مفاتيح إنتاج أو node_modules. قائمة الملفات المعدلة موجودة داخل حزمة التعديلات.
