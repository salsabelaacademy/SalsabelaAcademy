# تحديث القائمة والإشعارات والملف الشخصي

تُطبّق هذه الحزمة فوق تحديث تصميم لوحة المدير والطالب السابق (a531aa0).

## التركيب

1. احفظ نسخة احتياطية من مشروعك الحالي.
2. انسخ الملفات الموجودة بالحزمة إلى المسارات المطابقة داخل المشروع، واستبدل الملفات المطابقة فقط. لا تستبدل المجلدات كاملة.
3. شغّل `npm run check` ثم `npm run lint` ثم `npm run build`.
4. أعد تشغيل الخادم؛ التحديث يشمل واجهة المستخدم وملف الخادم `server/portal.ts`.
5. لا تحتاج إلى مفاتيح أو مكتبات جديدة أو ترحيل قاعدة البيانات.

## ما أصبح متاحًا

- قائمة جانبية بتدرّج كحلي وأخضر داكن ولمسات ذهبية. زر أعلى اللوحة لطيّها إلى أيقونات وتوسيعها، مع تذكّر الاختيار في المتصفح.
- تسميات للأيقونات عند المرور بالمؤشر، وأسماء متاحة لقارئ الشاشة، وإبراز للقسم الحالي.
- قائمة هاتف مستقلة، تدعم الإغلاق وEscape واستعادة التركيز، وتمنع تمرير الخلفية أثناء فتحها.
- جرس يفتح نافذة للإشعارات الحقيقية، حتى خمسة إشعارات مرتّبة بغير المقروء أولًا ثم التاريخ. يمكن تحديد الإشعار كمقروء وعرض القائمة كاملة.
- تصحيح طلب تحديد الإشعار كمقروء من POST إلى PATCH وفق واجهة الخادم الموجودة.
- إزالة المناهج من التنقل والإجراءات السريعة وإحصاء الوحدات من الملخص. تبقى بيانات المناهج السابقة محفوظة؛ لم تُحذف من قاعدة البيانات. يمكن الاستمرار في مشاركة الملفات أثناء Zoom.
- قسم الملف الشخصي للدورين، ويمكن فتحه أيضًا من دائرة الحساب أعلى الصفحة، حتى على الهاتف.
- المدير يعدّل اسمه. الطالب يعدّل اسمه ورقم التواصل والبلد والمنطقة الزمنية واللغة. يُحفظ الاسم في الحساب ويظهر فورًا في اللوحة وبعد إعادة تحميل الصفحة.
- بريد تسجيل الدخول ظاهر للقراءة فقط. يوجد رابط لتغيير كلمة المرور، وتبقى إدارة الجلسات في الإعدادات. لا يتضمن هذا التحديث رفع صورة شخصية أو تغيير البريد.

## تحقق بعد التركيب

1. ادخل بحساب المدير من `/ar/login` ثم افتح `/ar/dashboard/admin`.
2. اضغط زر الطي أعلى اللوحة، وأعد تحميل الصفحة للتحقق من تذكّر الاختيار.
3. افتح الجرس. إذا كان الحساب بلا إشعارات ستظهر حالة فارغة صريحة.
4. افتح الملف الشخصي، عدّل الاسم، واحفظ. تحقق من تحديثه أعلى الصفحة وبعد إعادة التحميل.
5. جرّب حساب الطالب في نافذة خاصة من `/ar/dashboard/student`، واحفظ بياناته والمنطقة الزمنية.
6. جرّب الهاتف والقائمة والجرس، ثم بدّل اللغة والوضع الداكن.

## نتائج الاختبارات

TypeScript وESLint وبناء الإنتاج نجحت. اجتازت الواجهة وواجهات الحساب والإشعارات 56 تحققًا مستهدفًا، منها الحفظ الحقيقي وإعادة التحميل، حماية حسابات الآخرين، رفض إدخال دور أو رقم مستخدم ضمن تحديث الملف الشخصي، رفض المنطقة الزمنية غير الصالحة، وإخفاء الملاحظات الخاصة.

فُحصت مقاسات 320 و375 و390 و768 و1024 و1440، وفتح قائمة الهاتف والنافذة المنبثقة والتركيز والوضع الداكن والتحويل للإنجليزية. جميع الاختبارات استخدمت قاعدة معزولة مع منع الاتصالات الخارجية؛ الصور المعروضة تحتوي على بيانات اختبار وليست بيانات أكاديميتك.

للتراجع، استعد الملفات المطابقة من نسختك الاحتياطية. لم تُجرَ تغييرات في بنية قاعدة البيانات.
